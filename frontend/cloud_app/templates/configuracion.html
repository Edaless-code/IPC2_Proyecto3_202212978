Formato del Archivo XML
El archivo XML debe contener:
  • listaRecursos: Recursos de hardware y software
  • listaCategorias: Categorías con configuraciones
  • listaClientes: Clientes con sus instancias
Ejemplo de estructura:
<archivoConfiguraciones>
  <listaRecursos>
    <recurso id="1">
      <nombre>Memoria RAM</nombre>
      <abreviatura>RAM</abreviatura>
      <metrica>GiB</metrica>
      <tipo>Hardware</tipo>
      <valorXhora>0.75</valorXhora>
    </recurso>
  </listaRecursos>
  ...
</archivoConfiguraciones>
